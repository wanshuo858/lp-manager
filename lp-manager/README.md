# LP 管理台（本地只读 MVP）

面向个人自用的本地网页应用，可查询配置的 Uniswap V3 / PancakeSwap V3 Position Manager 中的 NFT 仓位。不会连接钱包、索要助记词或私钥，也不会提交交易。

## 启动（Windows）

1. 安装 Node.js LTS（如果电脑还没有）。
2. 双击 `start.bat`，首次会安装依赖。
3. 浏览器打开 `http://127.0.0.1:5173`。
4. 选择链和协议，输入钱包地址及对应的官方 Position Manager 地址，点击查询。

## 已知范围与稳定性说明

- 目前仅读取仓位 NFT、代币符号、费率档位、tick 区间、流动性和合约中已记录的 `tokensOwed`。
- 尚未实现实时代币余额、价格估值、区间价格换算、历史盈亏、自动发现部署地址或钱包签名。
- Robinhood 配置当前标为测试网，RPC 与浏览器地址需在实际使用前核验；不要据此认为主网已支持。
- 查询依赖 RPC 和手动填写的 Manager 地址。请仅从协议官方文档/官方渠道核实部署地址。错误地址会导致查询失败，或产生误导数据。
- V3 Position Manager ABI 的 enumerable 方法在多数官方部署可用；若某部署不支持，查询会报错。后续可补充通过 Transfer 事件枚举的兼容索引方案。
- `tokensOwed` 是仓位合约当前记录的待领取数量，不是法币价值，也不一定含尚未 poke/结算的实时手续费增长。
- 该应用只绑定本机回环地址，不应将开发服务器暴露到公网。
